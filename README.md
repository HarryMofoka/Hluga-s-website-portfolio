# Lehlohonolo Mofokeng — Portfolio Site

HLUGA. — The portfolio of Lehlohonolo Mofokeng, a frontend developer in Johannesburg building fast, accessible and animated web experiences.

## Development

You need Node.js (v18+) and npm.

```sh
git clone https://github.com/HarryMofoka/Hluga-s-website-portfolio.git
cd Hluga-s-website-portfolio
npm install
npm run dev
```

## Built with

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
